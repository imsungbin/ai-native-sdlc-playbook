# Intent: a runnable companion repo for the AI-Native SDLC playbook
Author: imsungbin (repo owner). Status: accepted.

## Problem
Anthropic's playbook ships its configuration files inline in a blog post.
Anyone who wants to run its loop on their own project has to transcribe
them by hand, and has no worked record of the loop actually being followed.

## Proposed outcome
A repository containing the article's files verbatim, templates for its
three markdown artifacts, a single verification command, and this repo's
own intent to spec to plan record as evidence the loop was run.

## Affected users and systems
Readers of the article who want to adopt it; Claude Code in this repo.

## Constraints
Nothing added on top of the article. Every non-article decision is
recorded as an author's call. Product-gated features (MCP wiring,
sandboxing, Claude Security, Claude Tag) are named as out of scope,
not faked. Private repository.

## Open questions
Whether to publish the repository. Deferred; not decided here.

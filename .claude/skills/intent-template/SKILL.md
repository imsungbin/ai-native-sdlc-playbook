# Intent template

Write the intent as `intent/<NNNN>-<slug>/intent.md`, where NNNN is the next
unused four-digit number under `intent/`.

Use the headings in `templates/intent.md` exactly, in that order. Fill every
section; write "None." rather than leaving one empty. Keep the originator's
own words. Set `Status: draft.` The product owner changes it to `accepted`
when they commit it.
